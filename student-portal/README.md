# Student Portal Web Application

A fully functional, interactive, and responsive **Student Portal** web application built matching the visual design, pastel color schemes, gradient top bar, quick access cards grid, and upcoming events layout of the target screenshot.

## 🚀 How to Run

### Option 1: Direct Browser Launch (No Installation Required)
Simply open [`index.html`](file:///C:/Users/Adhvik%20dhakal/.gemini/antigravity/scratch/student-portal/index.html) in any web browser (Google Chrome, Microsoft Edge, Firefox, Brave, Safari).
- All 12 quick access cards, popups, instant search bar, notification drawer, chatbot, grade export, and fee payment workflows are 100% interactive out of the box!

### Option 2: Vite React Node.js Dev Server (Optional)
If you have Node.js installed on your system:
```bash
npm install
npm run dev
```

## ✨ Features Included

1. **Top Header & Search**:
   - Purple/indigo gradient header matching screenshot style.
   - Interactive student avatar & editable profile info ("Alex Johnson").
   - Notification Bell with red badge counter (3) and slide-over notification drawer.
   - Live Instant Search Bar ("Search anything...") filtering all modules, events, staff, and notices in real time.

2. **Quick Access Grid (All 12 Modules Fully Working)**:
   - 💜 **Profile**: View & edit full name, grade, roll number, email, phone with toast feedback.
   - 🧡 **Events**: Interactive school events with RSVP buttons and calendar sync.
   - 💙 **Staffs**: Searchable faculty directory with teacher details and instant message buttons.
   - 💚 **Attendance**: Monthly rate gauge (94.2%), subject-wise progress bars, absence log.
   - 🩷 **Chatbox**: Real-time AI support chatbot with automatic replies for student queries.
   - 💛 **GradeSheet**: GPA card (3.95/4.0), subject score list, and "Export PDF" button.
   - 🩵 **Gallery**: Photo grid albums with lightbox previewer.
   - 💚 **Fees Details**: Dues ledger ($350 pending), payment history, and interactive "Pay Now" simulation.
   - 💜 **Notices**: Latest updates circulars with "NEW" badges and category filters.
   - 🧡 **Assignments**: Active homework table, submission status, and file upload dialog.
   - 💚 **Exams**: Timetable, hall room locator, and downloadable Admit Card.
   - 💙 **Library**: E-book catalog search, borrowed books countdown, and one-click renewal.

3. **Upcoming Events Section**:
   - Science Exhibition (May 24) & PTM Meeting (May 28) cards with date badges, times, venues, and status tags.

4. **Responsive Dual View**:
   - Mobile Device Container Mode (matches exact screenshot layout).
   - Full Desktop Mode toggle button.
